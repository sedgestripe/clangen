# User Guides

This is a separate section of the wiki dedicated for guides created by players for players. We encourage players to PR their guides to this section, so long as it doesn't include the following:

- A guide to adding a specific mod. Keep this in your dedicated mod thread
- Linking to third party sites that require subscriptions
- Encouraging/Implying generative AI use
- A guide dedicated to a specific ClanGen feature. Save that for ClanGen's documentation page.

Information on utilizing our documentation system can be found in the [Contributing Section](../contributing/index.md).
